# GLeMM Lexicons Version 2.0.  German, English, French, Italian, Polish, Russian,  Spanish.

Two lexicons are provided for each language.

* A file `*_pairs.tsv` which contains the morphologically related lexeme pairs that have been formed from the resources (kaikki, MorphyNet, GLAWI) available for the given language.
* A file `*_defs.tsv` which contains the pairs which have a morphological definition in kaikki or GLAWI. It provides the same information as in the file `*_pairs.tsv`, with the addition of the original (raw) definition and the lemmatized definition.

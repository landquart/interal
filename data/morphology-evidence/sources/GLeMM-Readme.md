# GLeMM  Lexicons

GLeMM is a multilingual derivational morphological resource

## GLeMM\_1.3

GLeMM\_1.3 provides lexicons for English, French, Italian.  This version is based on the dictionaries [GLAWI](http://redac.univ-tlse2.fr/lexiques/glawi.html), [GLAW-IT](http://redac.univ-tlse2.fr/lexiques/glawit.html) and [ENGLAWI](http://redac.univ-tlse2.fr/lexiques/englawi.html). For French and Italian, GLeMM\_1.3 provides morphological families.

## GLeMM\_1.4

GLeMM\_1.4 provides lexicons for English, French, Italian.  The main change relative to GLeMM\_1.3 is the use of [Stanza](https://stanfordnlp.github.io/stanza/) to parse the English and Italian definitions.

## GLeMM\_2.0

GLeMM\_2.0 provides lexicons for German, English, French, Italian, Polish, Russian, Spanish.  In addition to [GLAWI](http://redac.univ-tlse2.fr/lexiques/glawi.html), [GLAW-IT](http://redac.univ-tlse2.fr/lexiques/glawit.html) and [ENGLAWI](http://redac.univ-tlse2.fr/lexiques/englawi.html), it uses data extracted from the [Kaikki](https://kaikki.org/dictionary/rawdata.html) dictionaries and from [MorphyNet](https://github.com/kbatsuren/MorphyNet) lexicons.

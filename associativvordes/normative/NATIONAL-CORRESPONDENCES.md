# Национальные соответствия — 1.0.0

Нормативная форма — свойство элемента Интераля. Национальная форма — свойство
подтверждённого употребления в конкретном языке, лексеме, значении и контексте.
Сходство формы является средством поиска, а не свидетельством членства.

| relation_type | Требуемое обоснование |
|---|---|
| exact_base | Точная основа и её релевантное значение, а не только строковое совпадение |
| documented_allomorph | Словарная/грамматическая запись варианта и конечная область применимости |
| sound_change | Документированное преобразование с языком, направлением и проверенными носителями |
| historical_shortening | Историческая цепочка сокращения именно в этой лексеме |
| compound_component | Сегментация, роль и значение компонента; не whole-word equivalence |
| indirect | Каждый шаг с from/to lexeme+sense ID, направлением и evidence IDs |
| accidental_similarity | Доказанная ложная сегментация/иной источник; сходство без источника остаётся unresolved |
| distant_etymology | Общий предок не доказывает нужную связь; требуется доказательство отсутствия требуемого морфосемантического пути для nonmember |

`correspondence.scope` обязан буквально совпадать с конечным scope решения;
никаких wildcard, регулярных выражений, префиксных диапазонов, межъязыкового
наследования и автоматического транзитивного расширения. Более общее
лингвистическое правило хранится отдельно; применение к каждой новой лексеме
требует собственного доказанного finite binding. `man-* → manu`, `reg-* → regul`
и снятие окончания без лексической проверки запрещены.

## Проверочные семейства

`cases.json` хранит ожидаемую классификацию, источник/ограничение и explanation.
Это учебные тесты применения правил, не сертифицированная массовая разметка.

| Элемент | Положительный пример | Отрицательный/пограничный |
|---|---|---|
| manu | fr manucure: manu-; ru маникюр: мани- через документированное заимствование | en many: man- не доказательство; перенос мани- на манифест запрещён без отдельного исследования |
| regul | fr réguler: régul-; règlement: règl- через règle; ru регламент — отдельная проверка заимствования | fr régule «металлический сплав» от regulus; regolith — иная основа; одно reg- ничего не разрешает |
| creat | fr création/créer различают créat-/cré-; es crear, de kreieren, it creare требуют собственных национальных свидетельств | creature с непрозрачным современным смысловым переходом не получает высокий A автоматически; create ≠ любая строка crea- |
| ocul | fr oculaire (глазной / окуляр) — два scope смысла | œil требует документированной исторической формы; binocular/Monokel не сертифицируются по общему происхождению без конечной цепочки |
| inter | fr interstellaire: доказанный компонент inter- «между» | intérêt: потенциальный исторический путь не равен современной прозрачности; internal нельзя принимать только по inter- |
| окончания | ни один общий хвост сам не создаёт семью | реальные de gelten/retten/erwarten из старого surface:de:ten остаются исключёнными |
| омонимы | отдельные лексемы liber «свободный» / «луб, книга» | английский liber «луб» не член family:liber «свобода»; неизвестный смысл не выбирается по буквам |

Проверенные словарные утверждения в `sources.json` пересказаны кратко.
Неполученные или недостаточные национальные свидетельства обозначены явно:
такие случаи UNRESOLVED, а не выдуманные подтверждения. Исторически подтверждённое
членство и `association_status=unknown|weak` совместимы.

# Real probes

18 original stage-03 records selected from phase-04 paths, two candidate questions per language (en/de/fr/es/it/ru). Original bytes and pinned artifact checksums remain in each record. These are real observations, never an invented corpus.

UDer 1.1: https://ufal.mff.cuni.cz/universal-derivations — individual resource licenses in `data/morphology-evidence/sources/source-lock.json` (not one blanket license).
MorphyNet: https://github.com/kbatsuren/MorphyNet at `378144f64df58c78db5245af19d16a511ccecf3a`, CC BY-SA 3.0. Original authors K. Batsuren et al.; original rows preserved and mapped by stage 03/04, not relabeled as verified analyses.
GLeMM source lock and attribution are inherited if a related row is added; the present 18-row probe contains UDer/MorphyNet only.

`v6.json.gz` is a finite projection of actual project registries, pinned v6 `9fff76431a86a06df6db69b64d7f2ca4c871f1b7`, prior v5 `d6780ebc693837cc4560a40672eb7ee39e8fa6f7`. It retains source hashes and current negative controls, not new memberships. `frequencies.json` contains 13 actual project records with original measurements, file hashes, commit and lemma locators. No POS or sense frequencies were invented.

## История и оценка влияния

Сохранены все 545 импортированных исторических решений и 348 028 конечных scoped ID, с исходными family IDs, языком, POS/sense scope, полномочиями и источниками. Версия history snapshot совпадает с сертифицированной версией этапа 04. Старые журналы не переписываются. Инженерная проверка, исследовательская гипотеза и OWNER_ACCEPTED_AT_RISK не становятся независимым лингвистическим gold.

Прямые family-scoped решения и связанная история alias-маршрута выдаются отдельно. Отказ под старым удалённым ID не переносится на все нынешние цели похожего alias. После гипотетического redirect API проверяет каждый исходный scope; не допускаются потеря старого ID, расширение отрицания и «последняя запись побеждает». Недоступная история блокирует операцию. `coverage_complete=false` остаётся: доступный импортированный реестр не устраняет неизвестные mappings всей истории.

Для 35 детерминированно выбранных глубоких контекстов сохранены полные затронутые исходные записи, original family records, морфологические claims, альтернативные heads/edges, исторические решения и точные source path/ordinal/hash. Выборка не заменяет полный реестр групп; любой другой group ID доступен тем же read-only API.

Модель влияния хранит исходное число рёбер, объединение старых ID, языковое покрытие каждой семьи, aliases и арифметическое возможное схлопывание. Это не оценка семантической избыточности. Во всех реальных результатах: source lemma delta 0, membership delta 0, alias delta 0, redirects [], new roots 0. Di, Pr, Sh, SWOW, A, F, P, FAv и FAₐ при отсутствии нужных bindings обозначены UNKNOWN; формулы/веса не менялись. Эффект гипотетического изменения для калькулятора остаётся UNKNOWN.

## Проверки и восстановление

Два свежих дисковых анализа совпали по всем логическим таблицам и всем экспортам. Независимая JS-реализация проверила весь production; отдельно пересчитан фактически сохранённый набор каждого membership в новой базе. Проверено сохранение суммарной инцидентности пересечений. Checkpoint после двух metadata buckets и после полного overlap phase возобновлён; операции идемпотентны. Тесты проверяют A–B/B–C без транзитивного слияния, разные языки, неустановленные значения, точные scoped negatives, недоступную историю, legacy heads и контракт исходного JS-хеширования.

Полный свежий импорт: около 787,5 с, пик около 115 MiB. Полный непрерывный анализ: около 520,6 с, пик около 149 MiB. Независимый raw JS-проход: около 104,8 с, пик около 397 MiB. Это метрики данного окружения. База и граф остаются на диске; полного графа в RAM нет. Benchmark различает непрерывный запуск и продолжение после overlap checkpoint.

При возобновлении чата прежняя временная среда была очищена. Для итогового выпуска выполнены новые импорты из заново восстановленного точного сертифицированного архива и новые полные анализы.

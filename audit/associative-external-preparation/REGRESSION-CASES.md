# Регрессионные случаи

| Риск | Конкретная проверка | Что считается ошибкой |
|---|---|---|
| Поиск REGUL | Реальные REGUL/regule aliases, fr régulier; конечное régul-правило и correction rows из закреплённого v6 | Потеря допустимой привязки, обход конечного scope или возврат запрета |
| Смешение lexical heads | Два head ID под одним model_key в диагностическом capture | Произвольное сведение разных голов к одной модели |
| Общая подстрока | Реальные случаи с prior exclusions; relation=substring_only/homonym и сравнение с gold | Положительное членство только из буквенного фрагмента |
| Возврат через fallback | Прежние тесты графа на direct/alias/fallback/path, candidate history и новые source ablations | Новый источник/путь восстанавливает запрещённое членство |
| Потеря ручных решений | Открытие той же очереди; rejection после смены evidence/POS; неизменяемые gold releases | Очистка истории, перезапись человеческой разметки sampler-ом |
| Дубли моделей | Повтор model_key и один independent_model_id под несколькими производными | Завышение числа независимых моделей |
| Утрата частоты | Сравнение frequency_observation по model_key + lexical_head_id, включая collision | Отсутствующий rank/частота скрыты нулём или потеряны при дедупликации |
| Изменение языков | Шесть обязательных явных language states; represented before/after | Пропавший язык молча меняет знаменатель |
| Ошибка источников | Выключение arcs до обхода; проверка каждого шага и восстановление SQLite savepoint | Путь использует исключённый источник или портит исходный граф |
| Ложный gold | Mode=model, отсутствие полномочий/независимого evidence, несовпадающие case hashes | Автоматическая/непрослеживаемая метка считается ручной истиной |
| Разногласия | Два разных ответа и арбитраж независимым третьим с хешами | Один источник или тот же автор сам устраняет противоречие |
| Неполная база A | Нет настоящего capture / усечённый поиск / неверный code lock | Заглушка названа действующим алгоритмом; пропуск назван отрицанием |
| Ошибка границ | Явные разные offsets одного реального target, неизвестные offsets отдельно | Неизвестная сегментация посчитана безошибочной |

15 тестов этапа 06 проходят на реальных lexical carriers и явно TEST-ONLY моделировании решений/снимков. Их искусственные labels не входят в опубликованный gold. Дополнительно проходят 16 тестов кандидатов, 18 графа и 13 импортёров через четыре Node-обёртки.

Новые проверки не утверждают, что live-production REGUL исправлен или вся кодовая база прошла тесты. Сквозное сравнение A/B и реальные before/after расчёты ожидают фактических выгрузок. Полный npm suite не запускался; прежнее расхождение PH/mater methodology-20260909 не изменялось. Защищённые runtime/formula/data пути не менялись.

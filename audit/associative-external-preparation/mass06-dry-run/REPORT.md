# Полный массовый dry-run — этап 06

Дата: 2026-10-22. **Исследовательский цикл выполнен полностью для всех 19 canonical семей закреплённого shadow v6 реестра. Семантическое применение предложений заблокировано.** Production v5 инвентарь не включён в заявленное покрытие, v5/v6 не переключались. Никаких изменений утверждённых memberships, lexical heads, aliases, формул и ручных решений.

Результат — 1 567 вопросов, 3 813 конкретных native-лексем, полный proposed-annotation snapshot, отдельные пересекающиеся очереди и настоящий handoff в существующий интерфейс разметки. Полнота этого потока не означает исчерпывающего обнаружения всех слов: поиск ограничен заранее заданными budgets.

Побитово совпали discovery manifests; после отделения явно названных volatile timestamps/run IDs/result refs совпали полный список вопросов, ID, классификации, собственные native paths, refs/исходные строки, группы и история. Недетерминированность LLM не измерена: реальных ответов нет. Статус NOT_RUN_NO_REAL_MODEL_RESPONSES, divergence=null; это не «нулевое расхождение моделей».

На **каждом из шести выполненных слоёв** annotation процесс действительно получал SIGKILL после fsync пяти результатов. Следующий процесс пропускал ровно пять уже записанных результатов и восстанавливал полный идентичный snapshot. Отдельно прерывалось discovery после первой family/language единицы: частичный CURRENT не публиковался; resume получал идентичный manifest. Точные native-дубли после восстановления — ноль.

Полный annotation backup восстановлен: 3 813 карточек, 3 813 результатов, 7 627 событий. [RESTORE.json](RESTORE.json) хранит hash ZIP, размер и результат проверки authority-цепочки. Backup — не одна временная SQLite-копия.

Дополнительно в независимой копии рабочего каталога убран completion marker, имитирующий прерывание перед публикацией. Отдельный finish-контроллер проверил и повторно использовал все шесть законченных ступеней, восстановил working state и создал **точно такой же архив**. Нет расширения по подстроке, обычных путей через непроверенный язык, инфлекций как деривации или автоматического признания MorphyNet/GLeMM независимыми.

## Контроль качества и блокирующие проблемы

Независимого человеческого gold по-прежнему нет. Точное сопоставление по family + language + native ID нашло 85 пересечений с frozen pilot; пригодных человеческих меток — 0. Прежние accepted/corpus labels, пути и LLM не использованы как gold.

Дополнительные массовые выборки: 60 случайных по закреплённому seed и 60 риск-ориентированных, 120 разных native-карточек, 240 требуемых независимых человеческих проверок. В этом запуске ответы не выдуманы и не заполнены. Точные слепые задания находятся в архивированном QUALITY.json. Это подготовленный контроль качества, **не завершённая человеческая проверка**.

| Блокирующая проблема | Конкретно необходимо |
|---|---|
| Нет независимого gold | Первое fixed pilot сравнение: 360 проверок 180 заранее закреплённых случаев; полный исходный пилот: минимум 1 787 проверок; разногласия требуют арбитража |
| Новые массовые случаи ещё не проверены человеком | 240 независимых проверок этих 120 разных случайных/риск-ориентированных карточек; не оценивать всё по одним лёгким примерам |
| Нет реальных B/C ответов | Сохранённые реальные ответы на тех же случаях и бюджете; платные вызовы только после отдельного разрешения и бюджета либо проверенная локальная модель |
| Не проверены значения семьи, sense identity и POS | Снабдить карточки проверяемыми семантическими и лексическими основаниями; морфология их не заменяет |
| Классы не калиброваны | Выполнить заранее закреплённые статистические gates на независимых данных и нетронутом holdout |
| Ограниченная область реестра | Этот результат покрывает все 19 закреплённых v6 семей; нельзя выдавать его за массовую очистку отдельного production v5 инвентаря |

Пороги **не изменялись**: precision lower bound 0.99; false-merge upper bound 0.001; familywise alpha 0.05 для 12 заранее заданных strata. При нуле наблюдённых ошибок последний gate по используемому точному one-sided binomial правилу требует минимум 5478 независимых gold-наблюдений на релевантный preregistered stratum. Это условный минимум при выполнении предпосылок независимости, не произвольное заявление о точности. Маленькая выборка 120 случаев не сертифицирует такой риск.

Precision/recall, семантические membership/merge/type errors и их CI остаются null/BLOCKED; знаменатель пригодных сравнений с gold равен нулю. Ноль фактически применённых merge/deletion не является измеренной нулевой семантической ошибкой.

Допустимы автоматические checksums, импорт, native-ID deduplication, candidate proposals и scheduling. **Ни один текущий кандидат нельзя применять автоматически.** All-manual share = 100%. Экономия человеческого труда не измерена; к production-очистке система по этим данным не допущена.

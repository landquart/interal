# Attribution

Uses the existing certified UDer 1.1, GLeMM 2.0 and MorphyNet data and project-native v6/legacy evidence. Revisions, original URLs, artifact IDs, licenses and checksums remain in the unchanged source-lock and frozen input manifests. Original source rows are stored losslessly with locators/revisions and are untrusted data, not instructions or independent gold.

See [source-lock](../../../data/morphology-evidence/sources/source-lock.json), [import documentation](../../../associativvordes/importers/README.md), [pilot attribution](../pilot-validation/ATTRIBUTION.md) and [pilot04 attribution](../pilot04-quality/ATTRIBUTION.md). No Flexor source is used. TEST_ONLY fixtures are not included as linguistic evaluation answers. Public snapshots remove keyed reviewer personal fields; the private original history is retained in frozen inputs and authority backups.

# Экспериментальный приоритет проверки

Это порядок ручной работы, а не Di, Pr, Sh, P или PI и не оценка качества семей. Формулы проекта не вызываются и не изменяются. Значение не хранится в таблицах методологии.

`score = Σ component[k] × weight[k]`. Шесть целочисленных весов 0..100, JSON-файл `--weights`; неполный/неизвестный набор или дробный коэффициент отклоняется. Веса по умолчанию экспериментальные и не калиброваны.

| Компонент | Вес | Политика |
|---|---:|---|
| frequency | 2 | max(0,6−floor(log10(min реального положительного rank)))); при отсутствии наблюдений вклад 0 с явным unknown |
| uncertainty | 3 | 2 за общий unresolved status; +1 при связанной конкурирующей задаче графа |
| merge_risk | 4 | 2 за неопределённую идентичность; +1 при другой предлагаемой семье |
| independent_evidence | 2 | До двух групп источников: UDer отдельно, GLeMM/MorphyNet вместе консервативно |
| model_impact | 1 | 0, поскольку влияние на лучшие модели не измерялось |
| calculation_impact | 1 | 0, поскольку изменения расчёта не моделировались |

Оригинальный frequency_score сохраняется лишь как измерение проекта, не используется вместо независимого методологического балла. Минимальный rank по нескольким одноимённым записям — только экспериментальная оценка заметности вопроса, не частотность конкретного значения. Сегментация, словоформы и приблизительная похожесть сами не повышают подтверждённость.

GLeMM/MorphyNet не считаются независимыми по числу строк; исходная lineage сохраняется. Даже группировка UDer является верхней экспериментальной эвристикой: полная независимость происхождения отдельных ресурсов не доказана. Веса и компоненты не создают автоматического принятия. Высокий риск может повышать приоритет именно потому, что случай опасен.

Отсутствующее влияние на модели/итоговый расчёт обозначено `impact_status=not_measured_no_calculation_simulation`, а не «влияния нет». Отсутствующие частоты не заменены синтетическими: в пилоте 0/71 кандидатов с доступным rank в выбранных шардах. Практическая калибровка, независимый gold set и расширение частотного покрытия остаются дальнейшей ручной исследовательской работой.

Для очереди новых основ rank берётся из реальных частотных наблюдений по той же шкале. Независимость её источников пока не оценена (компонент 0, явный experimental_reverse_source_independence_not_measured); общий смысл и возможное семейство остаются неизвестными.

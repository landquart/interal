## Человеческий этап

Зафиксированы 180 случаев во всех 72 ячейках. В 37 ячейках по 3 случая, в 34 по 2, в одной ячейке один доступный случай. Нужны **360 независимых эталонных проверок + 360 отдельных измерений времени**, затем независимый арбитраж разногласий. Два gold-участника и четыре участника времени не пересекаются. Один человек не видит одну leakage group в разных условиях. Это предварительная подвыборка; по ней нельзя объявить итоговое качество всех семей.

Для полного исходного пилота минимум — **1 787 ручных проверок** (1 406 + 381), без арбитража. При двойной проверке всех начальных 180 случаев полный объём составит 1918 проверок; исходных обязательных повторов среди этих 180 — 49. Подробности: HUMAN-BLOCKERS.json.

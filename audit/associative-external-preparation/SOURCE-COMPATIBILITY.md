# Совместимость источников

| Источник | Реальный формат | Сохранение и семантика |
|---|---|---|
| UDer 1.1 | DeriNet 2, 10 колонок | native ID, LEMID, lemma/POS, segmentation/features, primary parent, ordered Sources, OTHERRELS и все аннотации; ресурс внутри коллекции сохраняется |
| GLeMM 2.0 pairs | 7 именованных TSV полей | lemma1, cat1, lemma2, cat2, stem, exponent1, exponent2; направление неизвестно |
| GLeMM 2.0 defs | те же 7 + 2 | definition2, lemmatized_definition2; оригинальные шаблоны/определения сохраняются |
| MorphyNet derivation | 6 TSV полей | исходная/производная лексема, оба POS, аффикс, native operation; полная сегментация отсутствует, null |
| MorphyNet inflection | 4 TSV поля | lemma, form, grammatical features, segmentation; отдельные записи без деривационных claims |

DeriNet не требует одинаковой полноты всех ресурсов или порядка родителей перед детьми. Первичный родитель и альтернативные Sources сохраняются отдельно; OTHERRELS не теряется. Распознанные ID дополнительных связей проецируются в граф; неизвестные кодировки концов сохраняются как unresolved и диагностируются. Тип связи берётся из источника; отсутствие типа не заменяется угаданной деривацией.

GLeMM stem не считается лексической основой; exponents не становятся автоматически аффиксами, пара не объявляется непосредственной деривацией, порядок lemma1/lemma2 не устанавливает направление. Возможное наследование MorphyNet отмечено у всех записей на уровне набора, точное соответствие строк неизвестно. Две версии одного свидетельства не считаются независимыми голосами.

## Нормализация

| Область | Правило |
|---|---|
| Unicode | строгий UTF-8; NFC отдельно от оригинала; raw байты сохраняются |
| Диакритика | не удаляется |
| Регистр | исходный сохраняется; casefold только для поиска |
| POS | явная ограниченная таблица в коде; неизвестный native tag сохраняется, UPOS null |
| Языки | явные ISO aliases; GLeMM esp и MorphyNet spa → es, native code сохранён в lock |
| Лемма/словоформа | разные роли, инфлекция не создаёт словообразовательную модель |
| Алломорфы | автоматического сведения нет; оригинальные строки операции/аффикса сохранены |
| Омонимия | одинаковая NFC/casefold строка не означает тождество лексем или значений |
| Кириллица | транслитерация не выполняется; язык обязателен |
| Операции | native операция сохраняется; отсутствующая не реконструируется |

UDer ID ограничен ресурсом и релизом. У MorphyNet/GLeMM нет устойчивых словарных sense ID: staging использует консервативные ключи release/record/role, оставляя лексическое тождество неразрешённым. Межисточниковая дедупликация существует только для нормализованного представления claim; каждое свидетельство сохраняет ревизию, artifact, строку и raw hash. Такие представления не являются утверждёнными отношениями.

## Особенности языков

Английский: UDer CatVar и WordNet различаются по полноте/лицензии; CELEX data отсутствуют. Немецкий: DErivBase включён, CELEX data отсутствуют. Французский: Demonette и GLeMM не считаются независимыми подтверждениями всех совпадений. Испанский: esp/spa alias явный, MorphyNet inflection разделён на два файла; 24 пустые формы в карантине. Итальянский: DerIvaTario имеет собственную лицензию и структуру аннотаций. Русский: четыре различных UDer ресурса; MorphyNet inflection поставляется ZIP с CRLF, которые сохраняются. Никакого сведения русской транслитерации с кириллицей нет.

Числа покрытия приведены в [03-IMPORT-REPORT.md](03-IMPORT-REPORT.md). Все шесть языков имеют данные всех трёх проектов; это доступность файлов, не оценка лингвистического покрытия словаря.

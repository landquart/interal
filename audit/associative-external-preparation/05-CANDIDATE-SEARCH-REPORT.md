Полные SourceRevisionRef, EvidenceRef, типы и направления в `candidate-validation/METRICS.json` и `QUEUE.ndjson.gz`. Путь `пед → педик` специально показывает риск омонимии/ошибочной исходной семейной привязки: написание основы не доказывает нужное значение. `crear → creamiento` — реально наблюдённая строка, а не генерация; корректность лексемы и анализа предстоит проверить. `altern → Alter → gealtert` сохраняет именно спорный исходный анализ; обход не исправляет направление произвольно. Ни один пример не принят в семью.

Обратный поиск: 20 ограниченных исходных находок, сгруппированных в 12 вопросов отдельной устойчивой очереди новых основ (`unassigned`, не canonical root). Отрицательные решения этой очереди сохраняются при повторном обнаружении. Находки получены из реальных частотных записей через реальные входящие направленные отношения к реальным лексемам-основам; `creates_canonical_root=false`. Нет создания произвольных слов или canonical root. Значения отсутствуют в доступном лексемном срезе и явно unresolved; исходные определения в графе не подменяются придуманными sense ID.

README пакета содержит команды. Нет массового обхода всех семей, runtime-интеграции, пересчёта моделей или общего миллиона-записного поискового сервиса.

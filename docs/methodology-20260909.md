# Расчёты по редакции методологии от 09.09.2026

## Формулы

- G: взвешенное редакционное расстояние по графемам NFC. Замена диакритики, перестановка соседних графем и повтор соседней одинаковой графемы стоят 0,5; остальные операции — 1. Нормировка — по длине большей формы.
- PH: глобальное выравнивание сегментов IPA. Вставка и удаление стоят 1; замена определяется нормированным расстоянием между признаками. Неизвестный сегмент останавливает расчёт. Дифтонги не объединяются; аффриката объединяется при наличии связки IPA.
- A = min(Di, 0,45Di + 0,35Pr + 0,20(100 − Sh)). Направление оценки: от знакомого деривата к требуемому значению корня.
- P = 100(A/100)^0,65(F/100)^0,35.
- В пределах подтверждённой модели выбирается наиболее частотный дериват. После оценки моделей сохраняются пять наибольших P; в таблице они упорядочиваются по F. Балл языка — максимальный P; A берётся у того же деривата.
- FAᵥ и среднее A взвешиваются по числу носителей представленных контрольных языков. Охват рассчитывается отдельно относительно всех шести языков.
- Для аффиксов частоты различных лемм суммируются внутри каждого корпуса до усреднения корпусов и логарифмической нормировки.
- Интернационализмы: D ≤ 2 и D/L ≤ 0,25; если одна из форм короче четырёх графем, требуется точное совпадение.

## Неполные данные

Нулевая частота в полном списке участвует в среднем. Отсутствующий файл не считается нулём. Для отсутствующего слова в усечённом списке сохраняется интервал; верхняя граница IPM задаётся `cutoffIpm`, если она известна. Веса категорий фиксируются для языка и не перенормируются для отдельного слова.

Частоты кандидатов повторно проверяются по корпусам перед выбором представителей моделей. Сохранённые результаты прежней версии требуют перерасчёта. JSON содержит версию методологии, корпусные данные, первичную и повторную оценки, параметры запроса и интервалы.

Повторная оценка не подменяет первичную. Если расхождение меняет выбор опорного деривата, представительство языка или прохождение порога, окончательное принятие блокируется. Недоступная повторная оценка также требует проверки. Пороговые значения и веса остаются рабочими параметрами; контрольные примеры не заменяют проверку на носителях языка.
